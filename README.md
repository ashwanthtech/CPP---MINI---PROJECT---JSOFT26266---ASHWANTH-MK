# 🎓 Student Marks Analyzer – C++ Mini Project

## 📌 Project Overview
Student Marks Analyzer is a beginner-friendly C++ mini project developed as part of the **Module 1 – Programming Foundation**.

This program helps users analyze student marks and generate a simple report using basic C++ concepts.

## 🚀 Features
- Enter the number of students (1–100).
- Read and store student marks.
- Calculate total marks.
- Calculate average marks.
- Find the highest mark.
- Find the lowest mark.
- Count passed students.
- Count failed students.
- Repeat the analysis whenever required.

## 💻 Technologies Used
- Programming Language: C++
- Code Editor: Visual Studio Code
- Compiler: G++

## 📚 Concepts Used
This project demonstrates the following beginner-level programming concepts:

- Variables and Data Types
- Arrays
- Functions
- For Loops
- If-Else Statements
- Do-While Loop
- User Input and Output
- Return Statements

## ▶️ How to Run the Project

**Step 1:** Open the project in Visual Studio Code.

**Step 2:** Open the terminal.

**Step 3:** Compile the program:

```bash
g++ StudentMarksAnalyzer.cpp -o StudentMarksAnalyzer
```

**Step 4:** Run the program:

```bash
./StudentMarksAnalyzer
```
